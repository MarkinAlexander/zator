## Ветка `fix/webui-start-hardening` — PR №1 автору

База: свежий `upstream/zator`, 4 чистых коммита, ничего лишнего:

1. `webui: установка панели больше не валится без nohup` — гейт
   `webui_ensure_runtime_deps` не роняет установку; раннер стартует без
   nohup (setsid / trap-игнор + фон).
2. `webui: диагностика OpenWrt показывает syslog procd` — п.4 диагностики
   печатает хвост `logread`, сообщение об ошибке старта указывает на него.
3. `webui: на Keenetic предпочитаем родной uhttpd_kn` — приоритет
   uhttpd_kn > uhttpd в детекте и раннере; поиск бинаря вне PATH.
4. `webui: старт после стопа ждёт освобождения порта + повторная попытка` —
   стоп ждёт исчезновения слушателя (до 4с), старт ретраится через 2с.

Кейсы из эксплуатации (телеграм-группа): панель не ставилась при лёгших
фидах opkg; не поднималась при установленном uhttpd_kn; поднималась со
второго запуска после переустановки. Подробности: `docs/webui-fixes.md`.

## Ветка `feat/break-detect` — PR №2 автору

База: свежий `upstream/zator`, 4 чистых коммита:

1. `lua: автоматический детект «домен ломается обходом» + дифференциальная диагностика`
   — break-detector.lua, break-validator.sh + иниты, хуки в оба
   оркестратора, exclude_hostlist на 10 TCP-профилях, dpidetect-меню,
   деплой/удаление, два смоук-теста.
2. `lua/config: входящий RST доходит до circular_locked + ранний гейт`
   — `payload=...,empty` у ручных TCP-профилей, гейт пустых пакетов.
3. `z2r: source-строка dpidetect.sh + самолечение недостающих lib-файлов`.
4. `break: RAM-кэш вердиктов — переиспользование и периодическая чистка`.

Живая проверка на реальном ТСПУ: детектор сработал по meduza.io (3 RST →
запрос → вердикт FIXED_BY_STRATEGY без ложного исключения); первый
реальный клиент — kimberlite.io (BROKEN → авто-исключение). Логика:
`docs/break-detect.md`.

## Ветка `feat/dpi-detect-autoselect` — песочница

Всё выше + быстрый подбор стратегий «F» (`lib/autoselect.sh`):
baseline-гейт, HEAD-отсев без докачки, early-exit, ранжирование финалистов,
warm-кэш побед. Исследование с живыми замерами —
`docs/autoselect-research.md`, логика текущей реализации —
`docs/autoselect-design.md`.

Статус по решению владельца: реализация подбора НЕ нравится, будет
переделываться. Зафиксированные претензии (для будущей переделки):

- в авторотации автора (`circular_quality`) хосты, которым обход не нужен,
  жёстко закрепляются на стратегии 1 (3 успеха из 5 → lock) — «не ломает,
  но и не нужна»;
- быстрые проверки (F) не нравятся концептуально — держать только здесь.
